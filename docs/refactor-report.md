# 整理・軽量化 検証記録

実施日：2026年10月26日。対象：THE SNOW CHRISTMAS の主要5ページ。既存のローカル変更を維持し、この作業で公開・push・DNS変更はしていません。

## 結果

- 日本語を含む本文を変更前の5ページと照合。空白・整形を除く本文は一致。
- PC幅1440pxで見出し・本文・ボタン・ヘッダー・カードなど225要素のフォント、サイズ、色、背景色、角丸、幅、displayを比較。差分なし。
- 390px・320px幅で主要5ページの横方向オーバーフローなし。390px確認時、読み込み完了済み画像の破損なし。
- 16点の画像を原本を保持して最適化。対象ファイル合計：4,800,636 bytes → 3,028,712 bytes（36.9%削減）。ロゴは可逆圧縮、写真はWebP quality 88。
- 動作確認時のブラウザーエラーログなし。

## 変更内容

1. 共通HTMLの編集元を `partials/`、本文を `templates/pages/` に整理。生成物を直接編集しない構造に変更。
2. 日付・会場・共有URL・募金締切を `config/event.json` にまとめ、カレンダー・共有文・主要な表示へ反映。
3. CSS・JSのURL更新を内容ハッシュで自動化。手動のバージョン更新漏れを防止。
4. CSS/JS/HTMLを整形。旧粒子演出と32個の上書き済み宣言を整理。共通ヘッダーの完成スタイルを一箇所に集約。
5. 動きの停止・OS設定を共通管理。ボタン粒子のタイマーを停止中・非表示時に停止。ページ雪のスクロール計測を集約。お礼ページの描画を画面外・バックグラウンドで停止。
6. 長いガーランドSVGとお礼ページ専用CSS/JSを分離。素材の用途と未使用の3D素材を記録。
7. README、AI編集ルール、構造、素材、公開・戻し方の手順を整備。
8. ロックファイルと読取専用のCI定義を追加。Storybookや本番フレームワークは追加していません。

## 数値の範囲と残る確認

画像削減率は選択した16ファイルのバイト数であり、ページ全体の転送量や表示速度の改善率ではありません。全画像が同時に読み込まれるわけではありません。

読みやすい整形と共通制御の分離により、トップが参照するCSS/JSは14から17ファイル、非圧縮合計は131,035から157,678 bytesへ増えています。gzipをローカルで適用した参考値は39,162から41,545 bytes。配信サーバーの実際の圧縮・キャッシュ設定を測定した値ではありません。画像削減が今回の主な通信容量改善です。

表示確認はCodex内ブラウザーと画面幅エミュレーションで行いました。実機Safari/Android、スクリーンリーダー、本番回線でのLCP/INP/CLSは未測定です。CIは定義と同等コマンドのローカル実行まで確認しており、GitHub上ではまだ実行していません。

開場時間・未公開プロフィールは既存の未確定状態を維持。v89はユーザー指定の最新版として編集ルールに記録し、今回の画像再圧縮では元のシーンを差し替えていません。
