# 公開前チェック — 2026-10-26

対象：ローカル開発環境の5ページ。公開・pushはしていません。

## 修正したこと

- 全画面メニューとPeopleモーダルを開いている間、背後の雪・イルミネーション・ボタン粒子の更新を停止。閉じたら復帰し、利用者が選んだ一時停止設定は維持。
- ページ離脱時にページ全体の雪の描画予約を解除し、戻った際に再計測。
- 18個の画像タグに不足していた寸法や遅延画像の非同期デコード指定を追加。協賛ロゴも遅延読み込み。画像読込前の領域を確保し、画像展開による表示への影響を抑制。
- 自動チェックに画像のwidth/height検査を追加。
- 新しいメニューと画像属性でトップHTMLは65,653 bytes。未圧縮HTMLの予算を65,000から68,000 bytesへ調整。他の予算は維持。高速化したという根拠に、この予算変更を使用していません。

日本語本文とデザインは維持。本文ベースラインは今回変更していません。
